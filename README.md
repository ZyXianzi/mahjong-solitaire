# Mahjong Solitaire

A playable desktop Mahjong Solitaire game built with Python 3.14, uv, and
`pygame-ce`.

The game is inspired by the clean table-game presentation of Clubhouse Games /
51 Worldwide Games: mouse-first controls, fixed layouts, real Mahjong tile art,
and a solvable board generator.

## Current Scope

- English UI.
- Main menu with `Start Game` and `Quit`.
- Tabbed layout selection for Easy, Medium, and Hard.
- Three layouts per difficulty.
- Guaranteed-solvable boards with randomized removal paths and face placement.
- Classic Mahjong Solitaire selection and matching rules.
- Hint, undo, restart, invalid-click feedback, deadlock modal, and win modal.
- SVG Mahjong tile art loaded from `assets/tiles/`.

Out of scope for this 1.0-style version: scoring, save/load, sound effects,
settings, packaged app export, and multiple visual themes.

## Requirements

- Python `>=3.14`
- uv
- macOS, Windows, or Linux with a working Pygame display backend

The project uses `pygame-ce`, but imports it as `pygame`.

## Setup

Use a project-local uv cache. This avoids permission issues with sandboxed or
restricted user-level uv caches.

```bash
UV_CACHE_DIR=.uv-cache uv sync
```

## Run

```bash
UV_CACHE_DIR=.uv-cache uv run python main.py
```

The game opens a fixed `1280x800` Pygame window.

## How To Play

1. Click `Start Game`.
2. Choose a difficulty tab: `Easy`, `Medium`, or `Hard`.
3. Choose a layout card and click `Play`.
4. Remove the board by clicking pairs of free matching tiles.

A tile is free when no tile sits above it and at least its left or right side is
open. If a tile is blocked, clicking it gives visual feedback and a status
message.

## Controls

- Click a free tile once to select it.
- Click a second matching free tile to remove the pair.
- Click a second non-matching free tile to move the selection.
- `Hint` highlights one currently legal pair.
- `Undo` restores the last removed pair.
- `Restart` starts a new board for the current layout.
- `Menu` returns to layout selection.

Hints are unlimited and do not affect scoring because scoring is not part of the
current version.

## Matching Rules

- Characters, bamboo, dots, winds, and dragons match only identical faces.
- Any flower tile can match any other flower tile.
- Any season tile can match any other season tile.

Deadlock means tiles remain but no legal matching pair is available. The game
then shows `No Moves Available` with options to undo the last move or return to
the menu.

## Layouts

| Difficulty | Layouts | Tiles |
| --- | --- | --- |
| Easy | Pyramid, Arena, Cross | 72 each |
| Medium | Turtle, Bridge, Fortress | 144 each |
| Hard | Dragon, Castle, Spider | 144 each |

The difficulty labels currently come from layout shape and density, not from a
score multiplier or timer rule.

## Solvable Generation

Layouts are fixed coordinate templates. Each new game is generated by creating a
random legal removal sequence on the blank layout, assigning Mahjong faces to
that sequence, and validating the solution path before the board is shown.

If generation cannot produce a valid board within the retry limit, the game
shows a startup error instead of starting an invalid board.

## Project Structure

```text
main.py                       Root entrypoint
mahjong_solitaire/core.py     Board rules and data objects
mahjong_solitaire/levels.py   Fixed layout coordinate templates
mahjong_solitaire/generator.py
                              Solvable board generation and validation
mahjong_solitaire/app.py      Pygame app, rendering, input, and screen flow
assets/tiles/*.svg            Mahjong tile art used by the renderer
tests/                        Unit and app-flow tests
```

## Tests

```bash
UV_CACHE_DIR=.uv-cache uv run python -m unittest discover -s tests
```

Optional headless smoke check:

```bash
UV_CACHE_DIR=.uv-cache SDL_VIDEODRIVER=dummy uv run python -c "from mahjong_solitaire.app import MahjongApp; import time, pygame; app=MahjongApp(); [app.start_game(k) or app.draw(time.monotonic()) for k in ('easy','easy_arena','easy_cross','medium','medium_bridge','medium_fortress','hard','hard_castle','hard_spider')]; print('pygame smoke ok', app.board.remaining_count()); pygame.quit()"
```

For UI changes, also check the real desktop window. Headless Pygame screenshots
can miss macOS display-backend rendering issues.

## Development Notes

- Keep rule logic in `core.py` and `generator.py` testable without Pygame.
- Keep `main.py` as the root run target.
- Use uv for dependency changes and commit `uv.lock` when dependencies change.
- Keep player-facing text in English unless localization is explicitly planned.
- The tile renderer depends on the SVG filenames in `assets/tiles/`; update
  `tile_asset_name()` in `mahjong_solitaire/app.py` if the asset set changes.
